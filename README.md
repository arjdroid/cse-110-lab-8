# Lab8-Starter

Q: How are graceful degradation and service workers related?

A: Graceful degradation involves working around possible shortcomings in the technological limitations of the devices of visitors to your site, like a spotty network collection. Service workers are useful for this goal as they operate independent of your web app in the browser so they can operate things like network queries in the background and allow the web app itself to work even when temporarily offline, sending and receiving data.
